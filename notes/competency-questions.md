# Competency Questions (Ontology Test Plan)

These questions are used to validate whether the Alliance RFI ontology is useful for review, reasoning, and safe automation. If the model cannot answer these questions using only document-scoped entities and claims, the ontology needs refinement.

## Governance / Authority
1. Which claims in the RFI response could be mistakenly interpreted as delegated authority, and how are they explicitly bounded (or left unbounded) in the model?
2. Which offerings or capabilities are presented as possible, versus asserted as deliverable commitments (claims-only, not facts)?

## Security / Accreditation
3. Which claims depend on accreditation, air-gapping, or other security conditions, and where are those constraints represented?

## Offerings / Capabilities
4. What capabilities are bundled into the Core Offering, and which of those capabilities appear across multiple answers (reusable themes)?

## Constraints / Conditions
5. Which constraints are stated as prerequisites (must be true before action), versus constraints that are presented as design goals or intentions?

## Stakeholders / Perspectives
6. For a given claim, which stakeholder perspectives are most impacted (governance, security, delivery, reviewers), and what concerns drive that impact?
